# Deck edition changelog

Newest first.

## 6.0 (planned)

- Override bindings instead of saved ones, with a one-time clean-up of the saved binds (they were copied
  to the PC by Blizzard's server).
- Controller toggle through the interface-style setting (`InputDeviceInterfaceStyle`), without Find or Detect.
- Mode values re-applied at login; named Edit Mode layouts `YB Deck` and `YB Docked`.

## 5.5 (built, not installed)

- Controller section: "Find in options", detection that accepts only on/off values, clean-up of a wrong
  detected setting at login.
- Weapon hint: per-mode size and position, Move and Reset.

## 5.4 (installed on the Deck)

- Deck map tab, weapon hint, manual weapon set keys on R5 + D-pad left/right.
- Prowl, Enrage and Dash fire on press through hidden click buttons.

Earlier versions (3.x to 5.3) were delivered as zips and are not tracked here in detail.
