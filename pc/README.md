# PC edition (planned)

Addon `YagriverBindsPC` for WoW: Forever on the gaming PC, with two modes:

- **PC:** the 21:9 4K desk, keyboard and mouse.
- **Switch:** streamed through Sunshine/Vibeshine and Moonlight at 1080p; gamepad UI on, three wheels on
  bumper + trigger combinations.

Only the addon is needed on the PC; no Steam layout. Work starts with the YB Probe (phase 1 of the roadmap).
