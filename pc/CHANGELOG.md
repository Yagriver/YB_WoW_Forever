# PC edition changelog

Newest first.

## 1.1 (2026-11-22)

- Trigger check: looks for a sign the game gives while ZL / ZR are held (bar page, macro conditions,
  attributes of the gamepad bar's protected frames). If one exists, L1 / R1 can open wheels only
  while a trigger is held and keep Forever's targeting otherwise.
- Stick check in two phases (right stick, then left) with a big on-screen coach; the first second
  of each phase is ignored.

## 1.0 (2026-11-22)

- Modes PC (21:9 desk, keyboard UI) and Switch (16:9 Moonlight stream, gamepad UI), picked automatically
  from the screen shape at login and when the stream starts (6 s banner, "Stay" cancels).
- Per mode: UI scale, Edit Mode layout (picked by name, off by default), weapon hint size and position,
  right-stick-camera option (Switch).
- Weapon sets with keys chosen inside YB, as override bindings: never saved, never sent to the Deck.
- YB panel with phrases on secure buttons (no macros), channel buttons, weapon set buttons, professions.
- Check tab: Deck keys and macros that Blizzard copied here, conflicting addons.
- Stick check for the coming wheels.

## Probe 1.0 (2026-11-22)

- One-off test of the pad over Moonlight. Results in docs/ROADMAP.md.
